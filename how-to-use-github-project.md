# Create New Issue

To create a new issue, first hover over the "Backlog" lane and press "Add Item" below the existing items (alternatively, you can press the + icon in the top right of the lane).

<img width="543" height="399" alt="image" src="https://github.com/user-attachments/assets/8f4abf61-5b6d-4fb4-a6b8-ec7f92527a4e" />

&nbsp;

Then press the + icon in the bar that appears and select "Create New Issue".

<img width="697" height="162" alt="image" src="https://github.com/user-attachments/assets/a2e87d5f-7aca-457f-a5fe-6c1f8f21b735" />

&nbsp;

<img width="631" height="168" alt="image" src="https://github.com/user-attachments/assets/fc7bb493-27fb-4716-8886-4efb74edfc87" />

&nbsp;

Now select the "Default Issue Template".

<img width="1222" height="475" alt="image" src="https://github.com/user-attachments/assets/7c404340-82e9-4b1a-b83d-24ea524c6df1" />

&nbsp;

This should open a creation menu. In here you can fill in the title and description. Try to follow the template (it has instructions).
You can fill in the reviewer tasks now or leave that for when the issue is ready for review. You can leave the evidence/notes empty (or leave the placeholder text there) until the issue is ready for review.

<img width="1174" height="100" alt="image" src="https://github.com/user-attachments/assets/b2084257-d693-4fa8-8aee-8b32037cf263" />

&nbsp;

<img width="1165" height="732" alt="image" src="https://github.com/user-attachments/assets/270ea46e-3091-438c-88fe-442c1218ac7a" />

&nbsp;

You can also assign a person if it's already known who should do the task, and try to add the right label (in this example case it's a "programming/scripting" task)

<img width="579" height="742" alt="image" src="https://github.com/user-attachments/assets/03043c73-cbd4-42ca-96bd-cc5466df98cd" />

&nbsp;

<img width="514" height="727" alt="image" src="https://github.com/user-attachments/assets/3b9d8afe-840c-4075-ac36-fd5af8d7deea" />

&nbsp;

Now you can press "Create". But you're not quite done yet.

<img width="1164" height="417" alt="image" src="https://github.com/user-attachments/assets/429a7a90-8206-4197-b5ab-b9d5a45dc157" />

&nbsp;

After creating the issue, find it in the backlog lane and press it.

<img width="510" height="448" alt="image" src="https://github.com/user-attachments/assets/c8c9ae9f-56b1-4250-8a06-3b55a8903ebe" />

&nbsp;

This should open the issue preview. On the right side of this window, you can fill in the last information. Please indicate the priority (in this case, moving blocks is a MUST HAVE feature).

<img width="1878" height="943" alt="set issue priority" src="https://github.com/user-attachments/assets/4ab4127a-db6c-430d-b6b6-bd8985241265" />

&nbsp;

In the "development" section, you can also link this feature to a branch. For now, we can just link any issue that changes files in version control to the assignee's branch.

<img width="511" height="637" alt="image" src="https://github.com/user-attachments/assets/3ff5fcab-ee01-4ef2-94a5-422278f4428d" />

&nbsp;

Finally, you can indicate a relationship with other issues. In the example's case, it wasn't necessary, but it might be that you need something else implemented before the issue you just created can be done. In that case, select "Is Blocked By" and select the issue this just created issue depends on.

<img width="490" height="331" alt="image" src="https://github.com/user-attachments/assets/3707f66b-05f5-44ec-9020-1ba213df2206" />

&nbsp;

# Update Issue Progress

When working on the project, make sure to update your issue statuses. When you start working on an issue, please move the issue from "backlog" to "in progress"

<img width="639" height="625" alt="image" src="https://github.com/user-attachments/assets/475ba413-e761-4f19-8cd3-50b62821ed6a" />

&nbsp;

<img width="556" height="486" alt="image" src="https://github.com/user-attachments/assets/6c16ddd2-4f94-40fe-9f36-329a3901cb1f" />

&nbsp;

If for some reason, you cannot continue working on your issue, you can drag the issue to the "blocked" lane. When the blockage gets resolved, it can be moved back to "in progress".

<img width="1084" height="486" alt="image" src="https://github.com/user-attachments/assets/b86914ab-75f1-4cfb-a49c-0625e46f1d76" />

&nbsp;

When you finish working on your issue, you can move it to "in review".

<img width="1089" height="469" alt="image" src="https://github.com/user-attachments/assets/929bb2ef-1ac1-442e-ba77-1c7d843f281c" />

&nbsp;

The reviewer can review the issue. If the review isn't approved, the reviewer can move the task back to "in progress", and otherwise, it can be moved to "done".

<img width="1083" height="450" alt="image" src="https://github.com/user-attachments/assets/9b577277-4ec3-4345-ad6a-effcb2e95e64" />
